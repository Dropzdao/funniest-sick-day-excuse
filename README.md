A program that writes the funniest one-line sick-day excuse — a smart fridge locking its owner out of the kitchen — to `/output/entry.txt` for make.fun's "The Funniest Sick-Day Excuse" bounty.

The entry line (112 characters):

> Sorry, can't come in — my smart fridge locked me out of the kitchen and I've been negotiating with it since 6am.

## Run it

```sh
python3 main.py
```
